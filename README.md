# ポップンSUKIキャラグランプリ ランキング発表

ポップンSUKIキャラグランプリの発表順位と、その推移を楽しめる非公式ファンサイトです。

開催期間：2026年10月1日〜11月30日

## 見方

- グラフの横軸は発表日、縦軸は順位です。キャラクターのアイコンで順位を表示します。
- アイコンにカーソルを重ねると、キャラ名・初登場バージョン・おひさの有無が分かります。
- クリック・タップするとキャラ情報を表示し、そのキャラの推移を強調します。
- 最新発表のアイコン横にはキャラ名を表示します。ブラウザのページ内検索（Ctrl+F）で、表示中のキャラを探せます。
- 初登場バージョン・おひさの有無・順位帯で表示を絞り込めます。
- 順位が未発表のキャラは「発表待ち」で待機しています。

現在は10月9日の第1回と、10月15日の第2回中間発表（10月14日までの集計、各1〜300位）を掲載しています。両方の発表で順位が分かるキャラは、アイコンを線で結んで推移を表示します。最新発表に順位が掲載されていないキャラは「発表待ち」に表示します。
