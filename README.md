# ポップンSUKIキャラグランプリ ランキング発表

ポップンSUKIキャラグランプリの発表順位と、その推移を楽しめる非公式ファンサイトです。

開催期間：2026年10月1日〜11月30日

## 見方

- グラフの横軸は各回の集計日（その日までの投票を集計した日付）、縦軸は順位です。キャラクターのアイコンで順位を表示します。
- アイコンにカーソルを重ねると、キャラ名・初登場バージョン・おひさの有無と、集計日ごとの順位推移が分かります。順位が掲載されていない回は「順位未掲載」と表示します。
- クリック・タップするとキャラ情報を表示し、そのキャラの推移を強調します。
- キャラ以外の領域をクリック・タップすると、選択を解除します。
- 最新発表のアイコン横にはキャラ名を表示します。ブラウザのページ内検索（Ctrl+F）で、表示中のキャラを探せます。
- 初登場バージョン・おひさの有無・順位帯で表示を絞り込めます。
- 順位が未発表のキャラは「発表待ち」で待機しています。
- 開いたままの画面は自動更新されません。最新の掲載内容を確認するときは、ページを再読み込みしてください。

現在は10月9日・10月15日・10月22日・10月29日の第1〜4回中間発表（各1〜300位）と、11月7日の第5回中間発表（11月4日までの集計、上位30位＋ピックアップ6キャラ）を掲載しています。連続する発表で順位が分かるキャラは、アイコンを線で結んで推移を表示します。最新発表に順位が掲載されていないキャラは「発表待ち」に表示します。今回の掲載範囲は画面上にも表示し、過去の順位は引き続きグラフと順位推移のポップアップで確認できます。

第5回のピックアップは、110位ぐわんぜさま・111位アゲハ・112位ピエール＆ジル・221位フィリ・222位Ｓ．８．タロウ(Ｓ．８．タロウ＆おコン)・223位タマコです。これらのキャラも11月4日の位置に掲載しています。その他の未掲載キャラの順位は分かりません。

各回の集計日は、第1回から順に10月8日・10月14日・10月21日・10月28日・11月4日です。グラフ上の位置と日付表示は、この集計日を基準にしています。

総投票数は第4回発表時点で8,446,325票、前回から2,195,881票増えています。第5回の総投票数は本サイトでは掲載していません。
