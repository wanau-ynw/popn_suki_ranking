# ポップンSUKIキャラグランプリ ランキング発表

ポップンSUKIキャラグランプリの発表順位と、その推移を楽しめる非公式ファンサイトです。

開催期間：2026年10月1日〜11月30日

## 見方

- グラフの横軸は各回の集計日（その日までの投票を集計した日付）、縦軸は順位です。キャラクターのアイコンで順位を表示します。
- 実線は連続する発表の順位を結びます。点線は、一部順位のみの発表回で未掲載だった区間をまたぎ、前後の分かっている順位を結びます。点線の途中の順位は未掲載です。
- アイコンにカーソルを重ねると、キャラ名・初登場バージョン・おひさの有無と、集計日ごとの順位推移が分かります。順位が掲載されていない回は「順位未掲載」と表示します。
- クリック・タップするとキャラ情報を表示し、そのキャラの推移を強調します。
- キャラ以外の領域をクリック・タップすると、選択を解除します。
- 最新発表のアイコン横にはキャラ名を表示します。ブラウザのページ内検索（Ctrl+F）で、表示中のキャラを探せます。
- 初登場バージョン・おひさの有無・順位帯で表示を絞り込めます。
- 順位が未発表のキャラは「発表待ち」で待機しています。
- 開いたままの画面は自動更新されません。最新の掲載内容を確認するときは、ページを再読み込みしてください。

現在は10月9日・10月15日・10月22日・10月29日の第1〜4回中間発表（各1〜300位）、11月7日の第5回中間発表（11月4日までの集計、上位30位＋ピックアップ6キャラ）、11月12日の第6回中間発表（11月11日までの集計、1〜300位）を掲載しています。最新発表に順位が掲載されていないキャラは「発表待ち」に表示します。過去の順位もグラフと順位推移のポップアップで確認できます。

第5回のピックアップは、110位ぐわんぜさま・111位アゲハ・112位ピエール＆ジル・221位フィリ・222位Ｓ．８．タロウ(Ｓ．８．タロウ＆おコン)・223位タマコです。これらのキャラも11月4日の位置に掲載しています。第5回でこの範囲に含まれないキャラの11月4日時点の順位は未掲載です。10月28日と11月11日の両方に順位があるキャラは、この区間を点線で結びます。

各回の集計日は、第1回から順に10月8日・10月14日・10月21日・10月28日・11月4日・11月11日です。グラフ上の位置と日付表示は、この集計日を基準にしています。
